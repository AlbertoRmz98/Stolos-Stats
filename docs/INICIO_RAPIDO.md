# Inicio rápido (sin programar)
1. Descomprime el ZIP en tu computadora.
2. Abre el repositorio de GitHub.
3. Pulsa **Add file → Upload files**.
4. Arrastra los archivos y carpetas del ZIP descomprimido, incluyendo `.github`.
5. Pulsa **Commit changes**.
6. Abre **Actions → Daily Update → Run workflow**.
7. Abre el trabajo `daily-update` y revisa `Download historical sports data`.
8. Cuando aparezcan los JSON en `data`, publica con **Settings → Pages → Deploy from a branch → main → /(root)**.
Si algo falla, manda una captura del error del paso de descarga.
